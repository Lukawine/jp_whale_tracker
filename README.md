## 🇨🇳 项目简介 (中文)

这是一个用于自动监控、下载和分析东京证券交易所 (TDnet) 上市公司公告的 Python 工具。该项目旨在帮助用户高效地筛选和获取感兴趣的财务披露信息。

### 主要功能
*   **自动抓取**: 定时监控 TDnet 发布的最新公告（支持设定监控时间段）。
*   **智能过滤**: 支持根据**股票代码**和**特定关键词**（如“业绩预期”、“股份回购”等）筛选公告。
*   **内容提取**: 自动下载 PDF 和 XBRL/ZIP 文件，并提取其中的文本内容，便于后续处理。
*   **可视化界面**: 使用 Streamlit 提供友好的搜索、下载和管理界面。
*   **本地存储**: 使用 SQLite 数据库保存公告记录，文件保存在本地目录中。

### 快速开始

#### 1. 环境准备
确保已安装 Python 3.8 或更高版本。

#### 2. 安装依赖
```bash
pip install flask flask-sqlalchemy flask-apscheduler streamlit requests beautifulsoup4 pypdf lxml
```

#### 3. 运行后端
启动 Flask 服务器以处理数据抓取和 API 请求：
```bash
python app.py
```
* 服务器将在 `http://127.0.0.1:5000` 运行。
* 后端会自动启动定时任务进行数据抓取。

#### 4. 运行前端
启动 Streamlit 界面：
```bash
streamlit run streamlit_app.py
```
* 浏览器将自动打开 `http://localhost:8501`。
* 在侧边栏中添加股票代码即可开始监控。

## 🇯🇵 プロジェクト概要 (日本語)

東京証券取引所 (TDnet) の適時開示情報を自動で監視、ダウンロード、分析するための Python ツールです。関心のある企業の財務情報を効率的に収集・選別することを目的としています。

### 主な機能
*   **自動スクレイピング**: TDnet で公開される最新の開示情報を定期的に監視します（監視時間帯の設定が可能）。
*   **フィルタリング**: **銘柄コード**や**特定のキーワード**（例：「業績予想」、「自己株式」など）に基づいて開示情報をフィルタリングします。
*   **コンテンツ抽出**: PDF や XBRL/ZIP ファイルを自動的にダウンロードし、テキストデータを抽出します。
*   **Web インターフェース**: Streamlit を使用した使いやすい検索・管理画面を提供します。
*   **ローカル保存**: SQLite データベースを使用して履歴を保存し、ファイルはローカルディレクトリに保存されます。

### クイックスタート

#### 1. 動作環境
Python 3.8 以上が必要です。

#### 2. 依存ライブラリのインストール
```bash
pip install flask flask-sqlalchemy flask-apscheduler streamlit requests beautifulsoup4 pypdf lxml
```

#### 3. バックエンドの起動
データ取得と API 処理を行う Flask サーバーを起動します：
```bash
python app.py
```
* サーバーは `http://127.0.0.1:5000` で起動します。
* バックエンド起動時に、定期的なデータ取得タスクも自動的に開始されます。

#### 4. フロントエンドの起動
Streamlit インターフェースを起動します：
```bash
streamlit run streamlit_app.py
```
* ブラウザで `http://localhost:8501` が自動的に開きます。
* サイドバーで銘柄コードを追加することで、監視を開始できます。
